# 🍿 Персональный подбиратор кино и аниме с памятью вкусов

Консольная утилита на Python для поиска фильмов и аниме через внешний API. Программа запоминает предпочтения пользователя в локальном файле-куки (`cookies.json`), отсекает уже просмотренные тайтлы и собирает рекомендации на основе лайков.

## Что умеет скрипт

* **Запоминает предпочтения.** Сохраняет выбранный жанр, историю выдачи и понравившиеся тайтлы в `cookies.json`. При следующем запуске подбирает контент без лишних вопросов.
* **Отсекает повторы.** Сверяет новые ответы сервера со списком `seen_ids` в памяти и показывает только свежие варианты.
* **Работает с несколькими ресурсами API.** Подтягивает общие подборки по жанрам с одного эндпоинта и забирает похожие тайтлы по ID с другого.
* **Листает страницы (пагинация).** Подгружает следующие партии результатов по запросу пользователя.
* **Не падает при сбоях.** Обрабатывает опечатки в жанрах, пустые списки и обрывы сети через тайм-ауты и перехват исключений.

## Стек и зависимости

* Python 3.10+
* `requests` — для отправки HTTP-запросов к серверу.
* `python-dotenv` — для безопасного чтения API-ключа из файла `.env`.

## Структура проекта

* `main.py` — основной код программы и логика работы с API.
* `requirements.txt` — список внешних библиотек.
* `.env.example` — шаблон файла для хранения токена доступа.
* `.gitignore` — правила исключения для Git (скрывает `.env` и локальный `cookies.json`).

## Как запустить у себя

1. **Клонируй репозиторий и перейди в папку проекта:**
   ```bash
   git clone <[ССЫЛКА_НА_РЕПОЗИТОРИЙ](https://github.com/LukasMisyunas/APIChalange.git)>
   cd <ИМЯ_ПАПКИ>
   ```

2. **Установи зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настрой API-ключ:**
   Скопируй файл `.env.example`, переименуй его в `.env` и впиши свой токен:
   ```env
   API_KEY=твой_секретный_ключ
   ```

4. **Запусти скрипт:**
   ```bash
   python main.py
   ```
